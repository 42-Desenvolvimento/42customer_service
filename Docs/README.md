# Documentacao tecnica

Este diretorio centraliza notas tecnicas para desenvolvedores e operacao do
projeto Izing. Os documentos priorizam fluxos verificados no codigo-fonte e
devem ser mantidos curtos, com links para os pontos de entrada relevantes.

## Guias disponiveis

- [Sessoes e envio WhatsApp](./whatsapp-sessoes-envio-recuperacao.md) -
  inicializacao das sessoes multicanal, envio de mensagens WhatsApp,
  recuperacao apos falhas, eventos Socket.IO e diagnostico operacional.

## Como atualizar

1. Confira o fluxo no codigo antes de alterar o texto.
2. Prefira atualizar um guia existente quando o assunto ja estiver coberto.
3. Inclua caminhos de arquivos, variaveis de ambiente e exemplos concretos
   quando eles ajudarem na operacao ou manutencao.
4. Registre limitacoes conhecidas; nao descreva comportamento desejado como se
   ja estivesse implementado.
