# Documentacao tecnica

Esta pasta concentra notas tecnicas verificadas no codigo-fonte do projeto.
Use estes documentos para entender fluxos operacionais antes de alterar servicos
ou diagnosticar incidentes.

## Indice

- [Sessoes WhatsApp, recuperacao e eventos em tempo real](./whatsapp-sessoes-recuperacao.md)

## Como manter

- Atualize a pagina existente quando o comportamento documentado mudar.
- Prefira exemplos curtos com nomes de endpoints, eventos e variaveis reais.
- Nao copie segredos ou valores reais de ambiente para a documentacao.
- Quando houver duvida, valide no codigo antes de descrever o fluxo.
